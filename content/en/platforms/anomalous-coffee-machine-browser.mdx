### Saving Your Progress in a Browser Session

Browser-based visual novels usually store progress in local browser storage rather than a server-side account. In practice, that means a few simple habits keep your saves alive: use the same browser and the same browser profile every time, avoid clearing site data or cookies for itch.io, and don't rely on incognito or private windows for anything you want to keep.

If you're mid-run and need to stop, look for an in-game save or menu option before closing the tab. Player experience with itch.io browser builds suggests that a clean exit through the game's own menu is far safer than simply killing the tab.

For most players, the Anomalous Coffee Machine browser route is plenty. The game is short, dialogue-driven, and not especially demanding, so the performance gap between web and desktop rarely shows up unless you're on an old machine, a weak Wi-Fi connection, or a browser loaded with dozens of extensions.

You should lean toward a download if any of these apply: your connection drops regularly, you want to play on a plane or during a commute, or you plan to leave the game open for long stretches while doing something else. In those cases, a local build removes an entire category of problems.

If the web player stutters, try these in order:

- Close other heavy tabs and streaming services.
- Disable extensions on the itch.io page for the session.
- Hard-refresh the page to pull the newest build files.
- Try a different browser — Chromium-based browsers tend to handle HTML5 game canvases most consistently.
- Lower your display scaling or zoom level to 100% if the game window renders oddly.

## FAQ

**Is there an official Anomalous Coffee Machine browser version?**
The reliable answer lives on the developer's itch.io page. itch.io supports in-page HTML5 play for many titles, and when a build is offered that way, a "Run game" button appears in the play area. If you don't see one, the page is offering a download instead — that's the intended way to play at that point.

**Do I need to install anything to play in a browser?**
No. A web build runs inside your browser with no installer, no disk space used, and no admin permissions needed. You do need a reasonably current version of Chrome, Edge, Firefox, or Safari, and a stable internet connection for the initial load.

**Will my progress be saved if I close the tab?**
It depends on the build. Most browser visual novels use local browser storage, so progress usually survives a refresh or a closed tab as long as you return in the same browser profile and haven't cleared site data. If saving matters to you, use the in-game save option before you leave.

**Can I play Anomalous Coffee Machine 2 in a browser too?**
The sequel from HoruBrain is published on itch.io as well, and it follows the same format as the original. Whether a web build is available depends on what the developer has uploaded, so check the second game's project page for its own play options rather than assuming they match the first.

**Which browser works best?**
In practice, Chromium-based browsers — Chrome, Edge, Brave — tend to handle HTML5 game canvases most consistently, especially for audio playback and fullscreen behavior. Firefox works well for most builds. If one browser gives you a black screen or silent audio, switching is the fastest fix.
