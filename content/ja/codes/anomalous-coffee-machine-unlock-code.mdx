## ステップバイステップ：エンディング、シーン、分岐を解放する方法

ゲームが提供するすべてを見たいなら、一度に1つの可動部分だけを動かすパズルのように扱いましょう。以下のアプローチは、プレイヤーが最も効率的なルートだと説明しているものを反映しており、初回プレイでも10回目でも機能します。

1. **リセットせずに1回の完全な通しプレイを終える。** 基準が必要です。自然に答えを選び、物語がどこに着地するか見てみましょう。
2. **選択を記録する。** メモアプリで十分です。何を出したか、どう返答したか、会話がどう終わったかを書き留めます。
3. **リプレイして、ちょうど1つだけ変える。** 材料を1つ、または返答を1つ変えます。結果が変われば、本当の分岐点を見つけたことになります。
4. **極端な選択を試す。** 礼儀正しい vs 率直、忍耐強い vs 短気、好奇心旺盛 vs 無関心。分岐型ビジュアルノベルは通常、微妙さよりも対比に報います。
5. **実験する前にセーブをバックアップする。** セーブフォルダを安全な場所にコピーして、失敗したプレイで進行状況を失わないようにします。
6. **最初のゲームをやり尽くしたら続編に移る。** 一部のコンテンツと文脈は引き継がれます。

| ステップ | 行動 | 役立つ理由 |
|---|---|---|
| 1 | 完全な初見プレイ | デフォルトのエンディングを確立する |
| 2 | メモを取る | 同じ分岐を2回繰り返すのを防ぐ |
| 3 | 1回につき1つだけ変更 | どの選択が実際に重要かを切り分ける |
| 4 | 極端を押す | 隠し会話をより早く表面化させる |

## よくある質問

**Anomalous Coffee Machine には、すべてを一度に解放するアンロックコードがありますか？**
公式にはありません。開発者によって検証済みの万能コードは公開されていません。プレイヤーが話している Anomalous Coffee Machine のアンロックコードは、実はプレイスタイルです。分岐が開くまで、違う選択でリプレイすることです。

**ゲームにはいくつのエンディングがありますか？**
すべてのビルドとすべての細かなバリエーションを網羅する単一の公式カウントはありません。コミュニティ報告は、「別個の」エンディングをどう定義するかによって異なります。数字を追うのではなく、明らかに異なる反応をそれぞれ引き出すことを目指しましょう。

厳密には必須ではありませんが、強く推奨されます。続編はオリジナルのトーンと前提の上に成り立っており、再訪するプレイヤーほど多くを得られます。

**安全にダウンロードするにはどこから？**
オリジナルと続編の開発者公式 itch.io ページからのみにしてください。ミラーサイト、再パッケージされたダウンロード、無料リリースなのに支払い情報を求めるものは避けてください。

**解放内容を失うことはありますか？**
はい。セーブを削除したり、不注意に再インストールしたり、セーブエディタを実行したりすると、進行状況が消える可能性があります。実験する前にセーブフォルダをバックアップしてください。
