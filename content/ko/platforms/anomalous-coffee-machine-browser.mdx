## Anomalous Coffee Machine이란 무엇인가?

Anomalous Coffee Machine은 인디 개발자 HoruBrain이 제작하고 itch.io에 게시한 짧고 불안한 비주얼 노벨이자 인터랙티브 시뮬레이션입니다. 전제는 믿을 수 없을 만큼 단순합니다: 당신은 카운터 건너편에 있는 수수께끼의 소녀에게 커피를 서빙합니다. 커피를 내리고 대화하는 사이에 일어나는 일들이 바로 제목의 "anomalous(변칙적)"라는 단어가 존재 이유를 증명하는 부분입니다 — 삐뚤어진 대화, 초현실적인 장면, 그리고 장면이 전개되는 방식을 조용히 바꾸는 작은 선택들.

특히 Anomalous Coffee Machine의 브라우저 경험을 찾고 계셨다면, 바로 여기가 맞습니다. itch.io는 인디 카탈로그의 상당 부분을 아무것도 설치하지 않고 실행할 수 있는 웹 빌드로 호스팅하며, 이는 브라우저 경로가 게임이 실제로 어떤 것인지 가장 빠르게 확인할 수 있는 방법임을 의미합니다. 이 가이드에서는 웹 버전의 작동 방식, 다운로드와의 비교, 그리고 브라우저 세션이 제대로 작동하지 않을 때 대처법을 다룹니다.

브라우저 기반 비주얼 노벨은 일반적으로 서버 측 계정이 아닌 로컬 브라우저 저장소에 진행 상황을 저장합니다. 실제로는 몇 가지 간단한 습관으로 저장을 유지할 수 있습니다: 매번 동일한 브라우저와 동일한 브라우저 프로필을 사용하고, itch.io의 사이트 데이터나 쿠키를 지우지 않으며, 유지하고 싶은 것은 시크릿 또는 개인 정보 보호 창에 의존하지 마세요.

플레이 중간에 멈춰야 한다면, 탭을 닫기 전에 게임 내 저장 또는 메뉴 옵션을 찾으세요. itch.io 브라우저 빌드에 대한 플레이어 경험에 따르면, 게임 자체 메뉴를 통해 깔끔하게 종료하는 것이 단순히 탭을 강제 종료하는 것보다 훨씬 안전합니다.

다음 중 하나라도 해당된다면 다운로드를 선택하는 것이 좋습니다: 연결이 자주 끊기거나, 비행기나 통근 중에 플레이하고 싶거나, 다른 일을 하면서 장시간 게임을 열어두고 싶은 경우입니다. 그러한 경우 로컬 빌드는 문제의 전체 범주를 제거해줍니다.

웹 플레이어가 끊긴다면 다음을 순서대로 시도해보세요:

- 다른 무거운 탭과 스트리밍 서비스를 닫습니다.
- 해당 세션 동안 itch.io 페이지에서 확장 프로그램을 비활성화합니다.
- 페이지를 강력 새로고침하여 최신 빌드 파일을 가져옵니다.

## FAQ

**공식 Anomalous Coffee Machine 브라우저 버전이 있나요?**
신뢰할 수 있는 답은 개발자의 itch.io 페이지에 있습니다. itch.io는 많은 타이틀에 대해 페이지 내 HTML5 플레이를 지원하며, 그런 방식으로 빌드가 제공되면 플레이 영역에 "Run game" 버튼이 나타납니다. 보이지 않는다면 해당 페이지는 대신 다운로드를 제공하는 것입니다 — 그 시점에서는 그것이 의도된 플레이 방법입니다.

**브라우저에서 플레이하려면 무엇인가 설치해야 하나요?**
아니요. 웹 빌드는 설치 프로그램 없이, 디스크 공간을 사용하지 않고, 관리자 권한도 필요 없이 브라우저 내에서 실행됩니다. 다만 최신 버전의 Chrome, Edge, Firefox 또는 Safari와 초기 로드를 위한 안정적인 인터넷 연결이 필요합니다.

**탭을 닫으면 진행 상황이 저장되나요?**
빌드에 따라 다릅니다. 대부분의 브라우저 비주얼 노벨은 로컬 브라우저 저장소를 사용하므로, 동일한 브라우저 프로필로 돌아오고 사이트 데이터를 지우지 않았다면 새로고침이나 탭 닫기 후에도 진행 상황이 일반적으로 유지됩니다. 저장이 중요하다면 떠나기 전에 게임 내 저장 옵션을 사용하세요.

**Anomalous Coffee Machine 2도 브라우저에서 플레이할 수 있나요?**
HoruBrain의 속편도 itch.io에 게시되어 있으며 원작과 동일한 형식을 따릅니다. 웹 빌드가 제공되는지는 개발자가 업로드한 내용에 따라 다르므로, 첫 번째 게임과 일치한다고 가정하지 말고 두 번째 게임의 프로젝트 페이지에서 자체 플레이 옵션을 확인하세요.

**어떤 브라우저가 가장 잘 작동하나요?**
실제로 Chromium 기반 브라우저 — Chrome, Edge, Brave — 가 HTML5 게임 캔버스를 가장 일관되게 처리하는 경향이 있으며, 특히 오디오 재생과 전체 화면 동작에서 그렇습니다. Firefox는 대부분의 빌드에서 잘 작동합니다. 한 브라우저에서 검은 화면이나 무음 오디오가 발생하면 브라우저를 전환하는 것이 가장 빠른 해결책입니다.
