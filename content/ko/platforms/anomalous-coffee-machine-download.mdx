이것이 중요한 이유는 간단합니다: 독특한 이름의 인디 게임은 관련 없는 파일을 적절한 키워드로 포장하는 기회주의적 사이트를 끌어들입니다. 재포장된 설치 프로그램은 사람들이 컴퓨터에 정크 소프트웨어를 설치하게 되는 가장 흔한 경로입니다.

## 단계별: 게임을 다운로드하고 설치하는 방법

이 순서를 따르면 인디 릴리스에서 흔히 겪는 대부분의 번거로움을 피할 수 있습니다. 전체 과정은 보통 몇 분밖에 걸리지 않습니다.

| 단계 | 할 일 | 중요한 이유 |
|---|---|---|
| 1 | 공식 itch.io 페이지 열기 | 제작자의 빌드를 받고 있는지 확인 |
| 2 | 설명과 콘텐츠 태그 읽기 | 테마와 분량에 대한 기대치 설정 |
| 3 | 가격 또는 후원 옵션 확인 | 가격은 제작자가 정하며 바뀔 수 있음 |
| 4 | 다운로드 버튼 클릭 | 운영체제에 맞는 올바른 빌드 받기 |
| 5 | 나중에 기억할 수 있는 곳에 파일 저장 | 나중에 "어디 갔지?" 하는 상황 방지 |
| 6 | 압축 파일이면 압축 해제 | 대부분의 인디 빌드는 압축되어 배포됨 |
| 7 | 실행 파일 실행 | 첫 실행은 초기화에 잠시 걸릴 수 있음 |
| 8 | 페이지 북마크 | 향후 업데이트를 간편하게 만듦 |

Windows에서는 실행 파일을 더블클릭하는 것으로 보통 충분합니다. macOS에서는 서명되지 않은 인디 앱이 Gatekeeper 경고를 유발하므로 처음에는 마우스 오른쪽 버튼을 클릭해 Open을 선택해야 할 수 있습니다. Linux에서는 실행 전에 파일에 실행 권한이 필요한지 확인하세요.

페이지에서 원하는 만큼 지불(pay-what-you-want) 옵션을 제공한다면, 0을 입력하는 것이 종종 허용되지만 얼마간 지불하면 향후 업데이트를 지원하게 된다는 점을 기억하세요. 이는 기술적 요구 사항이 아니라 개인적 선택입니다.

## 흔한 다운로드 문제 해결

사람들이 겪는 대부분의 문제는 게임 자체의 버그가 아니라 일반적인 다운로드 문제입니다. 흔한 원인별 대처 방법은 다음과 같습니다.

| 문제 | 가능한 원인 | 해결 |
|---|---|---|
| 다운로드가 멈추거나 실패함 | 브라우저 시간 초과 또는 불안정한 연결 | 다시 시도하거나 다른 브라우저 사용 |
| macOS에서 파일이 열리지 않음 | 서명되지 않은 개발자 앱 | 앱을 오른쪽 클릭하고 Open 선택 |
| 백신이 파일을 경고함 | 작은 인디 빌드에 대한 휴리스틱 오탐 | 출처를 확인한 뒤 수동으로 허용 |
| 게임이 실행됐다가 종료됨 | 런타임 누락 또는 손상된 압축 파일 | 다시 다운로드하고 다시 압축 해제 |
| 브라우저 버전이 느리게 느껴짐 | 하드웨어 가속 또는 오래된 브라우저 | 브라우저 업데이트, 추가 탭 닫기 |
| 캐시 삭제 후 다운로드가 사라짐 | 파일이 로컬에 저장되지 않았음 | 공식 페이지에서 다시 다운로드 |

유용한 경험칙: 해결책이 백신을 완전히 비활성화하거나 "다운로더 도우미"를 설치하라고 요구한다면 멈추세요. 정당한 인디 릴리스는 둘 다 필요로 하지 않습니다.

- 파일 이름이 스토어 페이지에서 설명하는 것과 대략 일치합니다.

- 운영체제와 백신이 최신 상태입니다.

## 자주 묻는 질문

**공식 Anomalous Coffee Machine 다운로드가 있나요?**

**Anomalous Coffee Machine 다운로드는 무료인가요?**
가격은 공식 페이지에서 제작자가 정하며 시간이 지나면 바뀔 수 있습니다. 일부 itch.io 릴리스는 무료이고, 일부는 원하는 만큼 지불이며, 일부는 정가입니다. 간접적인 주장에 의존하지 말고 페이지 자체를 확인하세요.

**속편 전에 첫 번째 게임을 꼭 플레이해야 하나요?**
엄격히 요구되지는 않지만, 원작을 먼저 플레이하면 속편을 더 쉽게 감상할 수 있습니다. 두 게임은 형식과 분위기를 공유하므로, 첫 번째 게임이 사실상 두 번째 게임을 읽는 법을 가르쳐 줍니다.

**다운로드 대신 브라우저에서 플레이할 수 있나요?**
일부 itch.io 프로젝트는 다운로드 파일과 함께 브라우저 빌드를 포함합니다. 공식 페이지에 그 옵션이 나타난다면, 자신의 컴퓨터에 전체 **Anomalous Coffee Machine 다운로드**를 하기 전에 성능과 분위기를 테스트할 수 있는 좋은 방법입니다.
